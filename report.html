抓取、分析、判讀、產生報告都在本機完成（本機抓取、Claude 判讀），GitHub 只負責發布網頁；原始資料只存在本機。
  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今日的值從午夜累積到 07:00。
  • 本輪 45 / 47 站取得，來自氣象署開放資料 API。精忠與石碇(2)（連十八輪）兩筆缺測，直接排除，不以 0 補；石碇（連六輪恢復）、拉拉山、仙跡岩維持回報。環域半徑 9 km；「0 / N」代表 N 站都確認無雨，查無資料是另一回事。本輪 45 站午夜到 07:00 全 0，七地環域 0 / 12、0 / 11、0 / 13、0 / 7、0 / 8、0 / 4、0 / 4 都是確認無雨，沒有任何一地需要改用環域值。站名以專案站表為準：局屬站 466930 站表名稱為陽明山，自動站竹子湖另有一站。
  • 觀測時刻 07:00，抓取 07:11。卡片與判讀一律以觀測時刻為準，不以抓取時刻代替。日累積在午夜歸零；昨晚 21:00 到今晨 07:00 之間沒有其他快照，本頁不回答昨晚 21 時到午夜有沒有下雨；今天 00:00 到 07:00 的 0 是 07:00 那筆直接量到的日累積，06:00–07:00 與 06:50–07:00 全 0 則是同一筆的時雨量與 10 分鐘雨量。
  • 表格起算日：早上與中午抓取時兩張表含今天；午後與入夜抓取時改由明天起算。這次是 07:11 早上抓取，兩張表含今天 10/29；yr 的今天從取得時起算，10/29 列是 07 時以後的值；yr 這批延到 11/06 → 雨量表 9 列（10/29–11/06）、氣溫表 8 列（10/29–11/05），11/06 的氣溫寫在 11/05 列備註與判讀 ④。
  • 資料空檔：09/29 11:02 到 10/01 09:32、10/15 21:11 到 10/19 08:47 之間沒有抓取，這兩段期間的實測未取得，09/30 與 10/16–10/18 有沒有下雨本頁無法回答；這段期間的 yr 各批也沒有取得，軌跡直接由前一批接到後一批。10/26 07:11 到 18:35 之間也沒有抓取，這段時間發布的 yr 各批沒有取得，軌跡由 07:11 那批直接接到 18:35 那批。

  • 遠端日期的處理：第 4 天以外的數字只記錄不採用，進到 3 天內才用固定的三段判準（挪行程／帶傘／不追蹤）下結論，時程事先寫定，不因單版數字大小調整。兩次取得的 yr 數字若一字不差，視為同一批預報，只算一次：這批（10/29 07:11 取得）10/29、10/30、10/31 三天的雨量或氣溫和昨晚 21:10 那批不同（程式逐值比對）→ 新批、軌跡各加一筆；11/01 到 11/06 六天七地逐值一字不差 → 同一批重複取得，只算一次、不加筆，11/06 仍只有一批證據。
