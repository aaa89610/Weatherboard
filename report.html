09/23 與 09/24 七地全部 0 mm,09/25 也只有台北 0.6 mm、新北四區 0.1–0.2 mm、新竹竹北 0 mm——量級在測不出來的等級。

這三天的 0 已經連續六版沒有動過,是整份預報裡唯一穩定的部分。

判讀09/23–09/25 的戶外行程可以照排,不需要備案。

③ 降雨訊號提前到 09/28–09/29,但量級仍不可引用 只看方向

本版把轉折往前挪了:09/28 由 0 變成七地 1.6–3.3 mm(新竹竹北 3.3 最多),09/29 台北跳到 18.1 mm、板橋中和 11.4、土城樹林 7.0、新竹竹北 1.4。

但同一組數字上一版長得完全不同:09/30 昨天還是台北 46.9 mm,這一版只剩 5.3 mm。再往前一版,09/30 甚至是 0。同一天在三版之間走了 0 → 46.9 → 5.3。

換句話說,第 6 天以後模式給的是「這段期間會轉濕」,不是「哪一天下多少」。本版再往後的 10/01 也有台北 11.5 mm,同樣屬於這個不確定的區段。

判讀把 09/28 之後當成乾期可能結束的時間帶,不要拿 18.1 或 5.3 這些數字做決定。要看量,等它進到 5 天以內再說。

④ 高溫回到 33–34°C;09/29 新竹反而比台北熱 6°C 回溫

今日(09/22)台北只有 23°C 上下,是這段期間最涼的一天。09/23 起高溫回到 31°C,09/26–09/28 新北四區可達 33–34°C,日夜溫差約 10°C(早上 22–24°C、午後 33°C)。

新竹與竹北平常高溫比北北低 3–4°C(09/26–09/28 為 30°C vs 34°C),低溫則相近。但 09/29 反過來:新竹竹北 26–35°C,台北只有 25–29°C,新竹的高溫比台北高了 6°C。

這個反轉和雨量對得上——09/29 台北預估 18.1 mm、新竹竹北只有 1.4 mm,北部有雨壓低了白天溫度,新竹沒下就照常曬。

判讀早晚溫差大,外套留著。09/26–09/28 北北下午偏熱要防曬補水;09/29 若真的照這個走向,反而是新竹竹北最熱,別以為北部熱就代表新竹也熱。

資料來源與方法

抓取、分析、判讀、產生報告都在 Claude session 內完成,GitHub 只負責部署。
  • 數值語意:卡片上的 mm 是本日累積雨量(RainfallElement.Now),不是瞬時或時雨量。
  • 本輪 47 站全數取得,無缺測站。環域半徑 9 km,七地合計 62 站次;「0 / N」代表 N 站都確認無雨。
  • 觀測時刻 20:20,抓取 21:14——氣象署此次提供的 ObsTime 與抓取時間相隔約 50 分鐘,卡片與判讀一律以 20:20 為準,不以抓取時刻代替。
  • 缺漏一律標「未取得」,不以鄰區數值代填、不內插、不編造。
  • 氣溫來源:yr.no 逐日最低／最高溫,四捨五入到整數;新北四區以板橋為代表(板橋、中和、土城、樹林四地差異在 1°C 以內)。氣溫與雨量皆為預報值,非實測。
