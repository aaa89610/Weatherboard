資料來源與方法

抓取、分析、判讀、產生報告都在 Claude 雲端排程完成（雲端抓取、Claude 判讀），GitHub 只負責發布網頁；原始快照不上傳，每輪的數字與待辦記在 git 的判讀紀錄裡。
  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今天的值從午夜累積到觀測 11:00（今天第二筆）。代表站 0 但環域有雨時改用環域最大值、標「局部有雨」——這輪七地代表站與環域都是 0，沒有這種情況。
  • 本輪 47 / 47 站取得，來自氣象署開放資料 API（站碼直接比對）。環域半徑 9 km；「0 / N」代表 N 站都確認無雨，查無資料是另一回事；缺測站一律排除、不以 0 補。站名以專案站表為準。
  • 觀測時刻：氣象署 API 提供精確觀測時刻，這輪是 11:00（抓取 11:10）。
  • 表格起算日：早上與中午抓取時兩張表含今天；午後與入夜抓取時 yr 的今天只剩部分時段，改由明天起算，今天交給判讀 ① 用實測與氣象署交代。這次中午抓取 → 由 11/13 起算、窗口 11/13–11/15。yr 這批到 11/21 → 雨量表 9 列（11/13–11/21）、氣溫表 8 列（11/13–11/20，11/21 寫在 11/20 行尾）。
