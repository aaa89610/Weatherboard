資料來源與方法

抓取、分析、判讀、產生報告都在 Claude 雲端排程完成（雲端抓取、Claude 判讀），GitHub 只負責發布網頁；原始快照不上傳，每輪的數字與待辦記在 git 的判讀紀錄裡。
  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今天的值從午夜累積到觀測 16:00（今天第三筆）。昨天（11/23）21:00 之後到午夜沒有觀測，昨天全日總量未取得。代表站 0 但環域有雨的卡片，數字用環域最大值，標「局部有雨」——這輪七地代表站都接到雨，沒有這種情況。
  • 本輪 47 / 47 站取得，來自氣象署開放資料 API（站碼直接比對）。環域半徑 9 km；「0 / N」代表 N 站都確認無雨，查無資料是另一回事。站名以專案站表為準。
  • 觀測時刻：氣象署 API 提供精確觀測時刻，這輪是 16:00（抓取 16:11）。
