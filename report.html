  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今天的值從午夜累積到觀測 07:00（今天第一筆）。昨天（11/18）21:00 之後到午夜沒有觀測，昨天全日總量未取得。代表站 0 但環域有雨的卡片，數字用環域最大值，標「局部有雨」——這輪台北（貓空站 1.0）、板橋、中和、土城（新北站 0.5）是這種情況。
  • 本輪 47 / 47 站取得，來自氣象署開放資料 API（站碼直接比對）。環域半徑 9 km；「0 / N」代表 N 站都確認無雨，查無資料是另一回事。站名以專案站表為準。
  • 觀測時刻：氣象署 API 提供精確觀測時刻，這輪是 07:00（抓取 07:11）。
