② 10/04 的雨又回來了——上一版的警語兌現 訊號反覆

10/04 由連兩版的 0 回到 台北 5.4、板橋中和 3.5、土城樹林 4.2、新竹竹北 1.2 mm。今天一天之內,同一天的預報走了 27.9 → 0 → 0 → 5.4 這條路。

我在上一版明寫過:「連兩版都是 0」不是「確定不會下」的證據,只是模式沒有回頭。半天後就翻了。這條警語兌現得比我預期還快。

量級上要分清楚:現在的 1.2–5.4 mm 和昨晚那組 23–31 mm 不是同一回事,前者是帶傘、後者才是改行程。目前看是前者。

判讀10/04 仍然照原計畫走。它在第 7 天,還會再變,進到 3 天內再認真看。

③ 10/02 升級成這波最明顯的一天,七地一起上修 值得追蹤

10/02(五) 台北 9.0、板橋中和 5.8、土城樹林 4.7、新竹竹北 4.3 mm,七地全部超過 4 mm。傍晚那版新竹竹北還只有 0.3,這一版跳到 4.3——不再是北部單邊的事。

同一波裡其他天反而縮:10/01 台北 3.4 → 1.8,10/03 北部五地由 0.1–0.5 全部歸零。雨量沒有增加,是集中到 10/02。

10/05 也一起上修:土城樹林 1.4 → 4.9、板橋中和 1.1 → 4.2。表尾新增 10/06,七地 0.8–1.6 mm。

判讀10/02(五) 目前是這 9 天裡最該帶傘的一天。距今 5 天,還不到改行程的程度,但值得先記著。

④ 「下週北部轉涼」縮水了,我上一版寫過頭 修正前版

我在 16:02 那版寫「10/02、10/03 北部降到 28–30°C,比前幾天低 5–6°C」。這一版 10/02 回升到台北 30、新北 32°C,10/03 也由 29 升到 30°C。降溫幅度從 5–6°C 縮到 2–3°C。

連帶地,我上一版說的「南熱北涼」在 10/02 已經不成立(新北 32 對新竹 31,北部反而較熱);只有 10/03 還維持新竹 32 對北部 30。

這不是資料錯,是我把一版的降溫講得太滿。第 5–6 天的氣溫和雨量一樣會來回,寫「降 5–6°C」這種具體幅度本來就該更保守。

判讀下週五、六不要預期明顯轉涼,目前只剩 2–3°C 的溫差,穿著照這幾天準備就好。

資料來源與方法

抓取、分析、判讀、產生報告都在 Claude session 內完成,GitHub 只負責部署。
  • 數值語意:卡片上的 mm 是本日累積雨量(RainfallElement.Now),不是瞬時或時雨量;今日的值累積到 20:50。
  • 本輪 46 / 47 站取得,C0A640(石碇)缺測已排除、未以 0 補;該站不在七地環域內,七地合計仍為 62 站次。環域半徑 9 km;「0 / N」代表 N 站都確認無雨。
  • 觀測時刻 20:50,抓取 21:03。卡片與判讀一律以觀測時刻為準,不以抓取時刻代替。
  • 兩張表都由明天(09/28)起算。入夜後模式給的「今日」欄位只涵蓋剩餘幾小時,寫進表裡會被誤讀成當日高溫,因此今天只在判讀①以實測交代。
  • 缺漏一律標「未取得」,不以鄰區數值代填、不內插、不編造。
  • 氣溫來源:yr.no 逐日最低／最高溫,四捨五入到整數;新北四區以板橋為代表(四地差異本表最大 1.1°C,其餘日在 0.6°C 以內)。整數欄位可能因四捨五入邊界放大實際差距。氣溫與雨量皆為預報值,非實測。
