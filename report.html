  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今天的值從午夜累積到觀測 21:00（今天第四筆）。21:00 之後到午夜沒有觀測，今天全日總量未取得。代表站 0 但環域有雨的卡片，數字用環域最大值，標「局部有雨」——這輪新竹市是這種情況（代表站 0、環域新埔 1.0）。

  • 觀測時刻：氣象署 API 提供精確觀測時刻，這輪是 21:00（抓取 21:11）。
