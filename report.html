  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今天的值從午夜累積到觀測 11:00（今天第二筆）。這輪七地代表站與環域都是 0，卡片寫 0 mm；代表站 0 但環域有雨時才改用環域最大值、標「局部有雨」。

  • 觀測時刻：氣象署 API 提供精確觀測時刻，這輪是 11:00（抓取 11:10）。
