資料來源與方法

抓取、分析、判讀、產生報告都在本機完成（本機抓取、Claude 判讀），GitHub 只負責發布網頁；原始資料只存在本機。
  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今日的值從午夜累積到 11:00。
  • 本輪 46 / 47 站取得，來自氣象署開放資料 API。精忠恢復回報後連六輪都有（0），板橋、中和、土城環域維持 12、14、8 站；石碇(2)（連二十六輪）仍缺測，直接排除，不以 0 補；淡水、石碇、拉拉山、仙跡岩維持回報。環域半徑 9 km；「0 / N」代表 N 站都確認無雨，查無資料是另一回事。本輪 46 站午夜到 11:00 只有陽明山區三站 陽明山、鞍部、竹子湖 各 0.5 有量，都不在七地環域內、和 10:00 那筆同值，10–11 時的時雨量與 10:50–11:00 的十分鐘雨量 46 站全 0 → 09 時以前下的、之後沒再加；其餘 43 站 0；七地環域 0 / 12、0 / 12、0 / 14、0 / 8、0 / 8、0 / 4、0 / 4 都是確認無雨，10:00 那筆也全 0，沒有任何一地需要改用環域值。站名以專案站表為準。
  • 觀測時刻 11:00，抓取 11:10。卡片與判讀一律以觀測時刻為準，不以抓取時刻代替。上一筆是今天 10:00（七地環域也全 0）；再前一筆是昨天（10/30）16:00，之間沒有抓取（昨晚 21:00 與今早 07:00 兩輪沒跑），昨天 16 時到午夜七地有沒有下雨本頁未取得；日累積在午夜歸零，今天 00:00 到 11:00 的值由 11:00 這筆直接量到，不受昨晚影響。11:00 以後的實測要等下一筆。
  • 表格起算日：早上與中午抓取時兩張表含今天；午後與入夜抓取時改由明天起算。這次是 11:10 中午抓取，兩張表含今天 10/31；yr 今天的值從取得時起算，10/31 列是「11 時以後」的部分日值、低溫不是清晨最低（備註寫明）。yr 這批延到 11/08 → 雨量表 9 列（10/31–11/08，11/08 只記錄）、氣溫表 8 列（10/31–11/07，11/08 氣溫寫在 11/07 列備註與判讀 ④）。
  • 資料空檔：09/29 11:02 到 10/01 09:32、10/15 21:11 到 10/19 08:47 之間沒有抓取，這兩段期間的實測未取得，09/30 與 10/16–10/18 有沒有下雨本頁無法回答；這段期間的 yr 各批也沒有取得，軌跡直接由前一批接到後一批。10/26 07:11 到 18:35、10/30 16:11 到 10/31 10:12 之間也沒有抓取（後者是昨晚 21:00 與今早 07:00 兩輪沒跑），昨天 16 時以後到今天午夜的實測與這兩段期間發布的 yr 各批都沒有取得，軌跡由前一批直接接到後一批。

  • 遠端日期的處理：第 4 天以外的數字只記錄不採用，進到 3 天內才用固定的三段判準（挪行程／帶傘／不追蹤）下結論，時程事先寫定，不因單版數字大小調整。兩次取得的 yr 數字若一字不差，視為同一批預報，只算一次：這批（10/31 11:10 取得）只有今天 10/31 的雨量（台北 1.1 → 0.9）和早上 10:12 那批不同 → 今天列加一筆（第十四批）；11/01 到 11/08 八天的雨量與氣溫七地逐值一字不差（程式逐值比對）→ 同一批、不加筆，早上那批對昨天 16:11 的變化沿用。今天台北 1.1 → 0.9 可能只是 10–11 時那一小時從今天剩餘時段扣掉（該小時實測 46 站 0），本頁照字面套判準。

  • 缺漏一律標「未取得」，不以鄰區數值代填、不內插、不編造。
