資料來源與方法

抓取、分析、判讀、產生報告都在 Claude 雲端排程完成（雲端抓取、Claude 判讀），GitHub 只負責發布網頁；原始快照不上傳，每輪的數字與待辦記在 git 的判讀紀錄裡。
  • 數值語意：卡片上的 mm 是本日累積雨量，不是瞬時或時雨量；今天的值從午夜累積到觀測 16:00（今天第三筆）。昨天（11/21）21:00 之後到午夜沒有觀測，昨天全日總量未取得。代表站 0 但環域有雨的卡片，數字用環域最大值，標「局部有雨」——這輪七地環域全 0，沒有這種情況。
  • 本輪 47 / 47 站取得，來自氣象署開放資料 API（站碼直接比對）。環域半徑 9 km；「0 / N」代表 N 站都確認無雨，查無資料是另一回事。站名以專案站表為準。
  • 觀測時刻：氣象署 API 提供精確觀測時刻，這輪是 16:00（抓取 16:11）。
  • 表格起算日：早上與中午抓取時兩張表含今天；午後與入夜抓取時 yr 的今天只剩部分時段，改由明天起算，今天交給判讀 ① 用實測與氣象署交代。這次午後抓取 → 由 11/23 起算、窗口 11/23–11/25。yr 這批到 11/30 → 雨量表、氣溫表各 8 列（11/23–11/30）。
  • 判準：3 天窗口 = 兩張表前三列；yr 單日 30 mm 以上或窗口內相鄰兩日合計 30 以上挪行程（挪在承載雨量那天）、單日 1 mm 以上帶傘（照字面含 1.0）、1 mm 以下不追蹤；氣象署逐時降雨機率 30–50% 折傘留包包、50 以上帶傘（含 50），和 yr 的 1 mm 門檻各自套用、取較重的那個；降雨機率延到幾點就寫到幾點，深夜才有的 30% 寫成深夜在外的帶折傘；午後與入夜抓取時今晚的動作只看氣象署。
