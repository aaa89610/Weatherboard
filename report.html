  • 本輪 46 / 47 站取得，來自氣象署開放資料 API（站碼直接比對）；石碇(2) 未取得，直接排除、不以 0 補，該站在七地環域外。環域半徑 9 km；「0 / N」代表 N 站都確認無雨，查無資料是另一回事。站名以專案站表為準。
  • 觀測時刻：氣象署 API 提供精確觀測時刻，這輪是 11:00（抓取 11:10）。早上那輪 API 逾時改抓網頁、沒有精確觀測時刻，內文對照時寫「07 時那筆」。
  • 表格起算日：早上與中午抓取時兩張表含今天；午後與入夜抓取時 yr 的今天只剩部分時段，改由明天起算，今天交給判讀 ① 用實測交代。這次中午抓取 → 由今天 11/06 起算、窗口 11/06–11/08。yr 這批到 11/14 → 雨量表 9 列（11/06–11/14）、氣溫表 8 列（11/06–11/13），11/14 的氣溫寫在判讀 ④ 與氣溫表最後一列的備註。
