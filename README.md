# Weatherboard — 台灣北部六地逐時降雨預測

自動更新的降雨看板：台北市、新北市板橋／中和／土城、新竹市、新竹縣竹北市。

- 網頁：`index.html`（GitHub Pages 首頁）
- 當次資料：`data.json`
- 歷史原始快照：`history/YYYYMMDDTHHMM.json`

更新時間：每日台灣時間 07:00–21:00，每 2 小時一次（共 8 次）。

資料來源：中央氣象署（鄉鎮預報、36 小時、特報、QPF、雨量站）、yr.no（MET Norway / ECMWF）、meteoblue。
所有數值均來自來源實測或實際預報，未經推估捏造。
